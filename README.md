# 🥷 つるふぇったの手裏剣修行  
**Tsurufetta's Shuriken Training**

忍者になって手裏剣を投げるアクションゲームです。  
的の中央を狙って手裏剣を投げ、アイテムを集めながら氷爆弾を撃ち落とそう！

## 遊び方

1. 段位（初段 / 中段 / 上段）を選ぶ
2. 左右ボタンで照準を合わせて「手裏剣！」をタップ
3. 的の中央に当てるとアイテムがもらえる
4. 氷爆弾は手裏剣で撃ち落とそう（落とせないと毒で10秒間撃てなくなる）

### アイテム
| 色 | アイテム | 効果 |
|----|----------|------|
| 青 | 👑 水の王冠 | 次の投擲が二刀流 |
| 緑 | 🍵 お茶 | 飲むと嬉しい |
| 赤 | 🧊 氷爆弾 | 敵の攻撃を消し飛ばす |
| 黄 | 🌸 花 | 手裏剣が増える |
